# 11:11 THE CAFE — Vaishali Nagar, Jaipur

> **Good Food, Late Talks & Your 11:11 Spot.**  
> A bespoke, single-page web experience for **11:11 THE CAFE** located on Gandhi Path Road, Vaishali Nagar, Jaipur.

---

## 🎨 Visual Identity & Palette

- **Deep Mocha (`#432F2E`)**: Structural contrast, typography, and evening menu surface.
- **Pale Sky (`#C1DBE8`)**: Asymmetric hero block and interactive 11:11 wish element.
- **Vanilla Custard (`#FFF0B5`)**: 3-pillar feature strip, hero dish framing, and pricing highlights.
- **Soft Warm Ivory (`#FCFBF7`)**: Editorial background canvas ensuring WCAG AAA accessibility.

---

## 🍕 Core Features

1. **Minimalist Top Bar**: Centered geometric `11:11 THE CAFE` emblem with live opening hours status and instant table booking CTA.
2. **Asymmetric Color-Blocked Hero**: Showcase of the signature Loaded Grilled Corn & Herb Club Sandwich with zero text overlap.
3. **"Why Vaishali Nagar Hangs Out Here" Feature Strip**: 3-pillar Swiss layout detailing comfort cravings, open-air evening canopy, and pocket-friendly hangout vibes.
4. **Interactive "11:11 Make a Wish" Widget**: Live digital clock with tactile spring bounce, celebratory confetti, and secret table discount/cookie code generator.
5. **All-Day Menu**: Featuring the Loaded Grilled Corn Club Sandwich & Classic Delhi-Style Chole Bhature Platter with interactive category tabs.
6. **Contactless QR Ordering Simulator**: Interactive table selection (Tables 01–12), item builder, and instant WhatsApp ordering.
7. **Squad Hangout & Birthday Table Booking**: Direct reservation form with WhatsApp forwarding, exact coordinates, and Google Maps integration.

---

## 🛠 Tech Stack

- **React 18** + **Vite 6**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Canvas Confetti**
- **Playwright** (Automated layout & visual audit)
